# Changelog

All notable changes to the **Pin & Hide** extension are documented here.

## [0.1.0] - 2026-11-03

### Added

- Visual Studio-style pin / unpin auto-hide for the Primary Side Bar, Panel and Secondary Side Bar.
- Pin buttons in each view's title bar.
- **Pin & Hide: Choose Pinned Parts…** multi-select command.
- Per-part toggle commands in the Command Palette.
- `autoHide.delay` setting (default `300` ms) controlling the hide delay.
- Pin state remembered between sessions.
